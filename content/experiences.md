Experience
One of my personal project that I developed to learn and test some technologies is a
service that can measure a ring size with the picture of a hand. It has been developed with
Python, NumPy, OpenCV, Machine Learning techniques to reduce the system error and
Docker. The main idea in the first moment, is to simplify the digital sales for rings, and then,
to start measuring any image with some point of reference. At now, this service can already
calculate the ring size with a coin as reference with an error about 2mm, so I considered a
machine learning model to try to reduce that error.
Disclaimer: This project was developed some time ago purely for educational purposes.
The intention behind mentioning it here is to convey my deep appreciation for image
processing and AI platforms, despite not actively working with these technologies at
present.
