One of the personal projects I developed to learn and experiment with new technologies is a service that estimates ring size from a photo of a hand.

It was built using Python, NumPy, OpenCV, Docker, and machine learning techniques aimed at reducing measurement error. The initial goal was to simplify the online purchase of rings, and later to explore how to measure objects in images using a known reference point.

At this stage, the service is able to estimate ring size using a coin as a reference, with an error margin of around 2 mm. To improve accuracy, I also explored the use of machine learning models.

Disclaimer: This project was developed some time ago purely for educational purposes. I mention it here to reflect my strong interest in image processing and AI platforms, even though I am not currently working directly with these technologies.
